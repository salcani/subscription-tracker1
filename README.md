
# Subscription Tracker

A simple web application for managing subscriptions.

## Features

- Add new subscriptions.
- View all subscriptions in a table.
- Delete subscriptions.
- Check subscription status.
- View total and expired subscriptions.
- Save subscription data using LocalStorage.

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub
- jsDelivr CDN

## Project Structure

- css-library/ - Custom CSS library
- js-library/ - Custom JavaScript library
- index.html - Home page
- add.html - Add subscription page
- subscriptions.html - Subscriptions table
- app.js - Main application logic
